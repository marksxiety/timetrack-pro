# Installation

## Prerequisites

- PHP >= 8.2
- Composer >= 2.5
- Node.js >= 18 (recommended: 20 LTS)
- npm >= 9
- MySQL

## Clone the Repository

```bash
git clone https://github.com/marksxiety/timetrack-pro.git
cd timetrack-pro
```

## Install Dependencies

```bash
composer install
npm install
```
